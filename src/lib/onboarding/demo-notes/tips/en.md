# Tips for everyday notes

## Find an action quickly

The command palette lets you run actions without searching through menus. Look up its shortcut and the note-search shortcut in **Settings > Hotkeys**. You can change shortcuts there too.

## Connect your ideas

Type `[[` and choose a note to insert a link. Links keep pointing to the same note when you rename it. Use folders in the sidebar to group notes that belong together.

## Write your way

Try headings, lists, quotes, and code blocks. Choose the visual editor, Markdown source, or a split view in Settings to suit how you write. You can also change the theme, text size, and line spacing there.

To revisit the setup choices and practice editor, open **Settings > General > Run setup again**.
