# Import, export, and backup

Mindstream uses open formats such as Markdown so you can take your text notes to other apps without vendor lock-in, while a local database supports saving, search, and sync.

Open **Settings > Data & Backup** to import notes, export them, or save a Mindstream backup.

## Bring existing notes

Import a folder of Markdown files, an Obsidian vault, a Joplin export, or an Evernote export. The import dialog walks you through the supported formats and reconnects links between imported notes.

## Take a copy with you

Export your notes as Markdown to read them in other apps. Use a Mindstream backup when you want to restore your workspace in Mindstream. Keep backups somewhere separate from your working vault.

Sync and backup have different jobs. [Sync and live collaboration](demo:sync) explains how changes travel between devices, including changes you might later want to undo.
