# Sync and live collaboration

Mindstream works offline without an account. To use your notes on several devices, connect the same account and server in **Settings > Account & Sync** on each device.

## Edits that merge

You can edit a note on two devices, even while offline. When they reconnect, Mindstream merges changes to the note's text automatically using a conflict-free document, so you do not have to choose between competing copies.

## Private, even on the server

Synced note content is end-to-end encrypted on your devices. The server stores and relays encrypted content without the keys to read it. Live collaboration uses end-to-end encryption too.

## Write together

Share a folder with another account on the same server and give them editing access. When you open the same note while connected, you can edit it together and see changes as they happen. Create a new note to try this, since these welcome notes cannot be shared.

Sync carries changes between devices, including deletions. Keep a separate backup of anything you want to recover later.
