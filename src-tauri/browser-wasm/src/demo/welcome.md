# Welcome to Mindstream Notes

Try writing here. Your edits save automatically in this browser and survive a reload.

## Try it out

- Open **Plan your week** and check off a task.
- Create a note with the new-note button in the sidebar.
- Switch between the visual editor and Markdown source.
- Drag a note tab to split the editor into two panes.
- Try a handwritten note, a drawing, or a Kanban board from the new-note menu.

## Your demo vault

These sample notes are yours to edit or delete. **Reset demo** deletes this demo vault's notes and attachments and brings the samples back.

Browser storage can be cleared by you or your browser. Export anything you want to keep. Use one demo tab at a time.

Download the app for desktop features and optional encrypted sync with a server you host yourself. This demo does not connect to a sync server.
