# Journal

**Journal** in the sidebar shows a month calendar. A dot marks a day with a
daily note; grey dots count the other notes created or last edited that day,
which are listed under the calendar for the selected day.

Click a day, or **Today**, to open that day's daily note. If it doesn't exist
yet, it's created. **Open today's note** does the same from the command palette
and can be given a shortcut.

## Settings

- **Daily notes folder**: where daily notes are created and looked up. Without
  one they go in the vault root.
- **Title format**: how a daily note is named, such as `YYYY-MM-DD` or
  `dddd, D MMMM YYYY`. A daily note is found by this title in that folder, so
  notes named with an earlier format, renamed or moved elsewhere no longer
  count.
- **Template**: a note to copy into each new daily note. Its placeholders are
  filled by the Templates plugin, and date placeholders such as `{{date}}` use
  the daily note's day.

## Removing it

Disable this plugin to remove Journal from the sidebar. Your daily notes stay.
