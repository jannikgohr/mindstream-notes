# Vorlagen

Erstelle neue Notizen aus selbst erstellten Vorlagen – es gibt keine
integrierten Vorlagen.

## Vorlagenquellen wählen

Lege unter **Vorlagenquellen** eine (oder beide) fest:

- **Vorlagenordner** – jede Notiz im gewählten Ordner (in beliebiger Tiefe) wird
  zur Vorlage.
- **Vorlagen-Tag** – jede Notiz mit dem gewählten Tag wird zur Vorlage.

Beide sind Auswahlfelder; wird der Ordner oder das Tag später gelöscht, setzt
sich die Einstellung selbst zurück.

Vorlagen funktionieren mit jeder Notizart – einer Markdown-Notiz, einem
Kanban-Board oder einer Plugin-eigenen Art wie einem Typst-Dokument. Besonders
gut passt das zu Typst: Bewahre ein vollständig gestaltetes `.typ`-Dokument als
Vorlage auf und erzeuge daraus neue Notizen mit bereits eingesetzten
Platzhaltern.

## Eine Vorlage verwenden

Öffne **Neu aus Vorlage** (die Schaltfläche in der Dateibaum-Leiste oder das
mobile Erstellen-Menü) und wähle eine aus. Aus Titel und Inhalt der Quellnotiz
wird eine neue Notiz **derselben Art** erstellt – wähle ein Typst-Dokument und
du erhältst ein Typst-Dokument.

## Entfernen

Deaktiviere dieses Plugin, um die Schaltfläche **Neu aus Vorlage** vollständig
zu entfernen.
