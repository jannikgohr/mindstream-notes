# Vorlagen

Erstelle neue Notizen aus selbst erstellten Vorlagen – es gibt keine
integrierten Vorlagen.

## Vorlagenquellen wählen

Lege unter **Vorlagenquellen** eine (oder beide) fest:

- **Vorlagenordner** – jede Markdown-Notiz im gewählten Ordner (in beliebiger
  Tiefe) wird zur Vorlage.
- **Vorlagen-Tag** – jede Markdown-Notiz mit dem gewählten Tag wird zur Vorlage.

Beide sind Auswahlfelder; wird der Ordner oder das Tag später gelöscht, setzt
sich die Einstellung selbst zurück.

## Eine Vorlage verwenden

Öffne **Neu aus Vorlage** (die Schaltfläche in der Dateibaum-Leiste oder das
mobile Erstellen-Menü) und wähle eine aus. Aus Titel und Inhalt der Quellnotiz
wird eine neue Notiz erstellt.

## Entfernen

Deaktiviere dieses Plugin, um die Schaltfläche **Neu aus Vorlage** vollständig
zu entfernen.
